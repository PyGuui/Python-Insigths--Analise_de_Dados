# 📊 Análise de Cancelamento de Clientes

Este projeto realiza uma **análise exploratória de dados (EDA)** com o objetivo de entender os principais fatores associados ao cancelamento de clientes e aplicar filtros estratégicos para reduzir esse comportamento.

---

## 🧠 Objetivos

- Entender o comportamento de cancelamento de clientes com base em variáveis como:
  - Número de ligações ao call center
  - Atrasos de pagamento
  - Tipo de contrato
- Visualizar a distribuição dessas variáveis por clientes que cancelaram ou não
- Aplicar filtros estratégicos nos dados para simular cenários com menor churn

---

## 📊 Tecnologias Utilizadas

- Python 3.x
- pandas
- plotly (para gráficos interativos)
